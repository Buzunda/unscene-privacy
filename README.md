# Unscene privacy policy

The public home of the Unscene browser extension's privacy policy, served by GitHub Pages at <https://buzunda.github.io/unscene-privacy/>.

The source of truth is `docs/privacy-policy.md` in the (private) Unscene repo. When it changes, copy it into `index.md` here, keeping the front matter at the top.

## Temporary home

This repo exists only until luizavila.dev is live. Then:

1. Publish the policy at `https://luizavila.dev/unscene/privacy`.
2. In the Chrome Web Store Developer Dashboard, set Unscene's privacy policy URL to the new address. No new review is needed for that.
3. Switch the contact email in the policy, and in the dashboard's account settings, to a luizavila.dev address.
4. Archive or delete this repo.
